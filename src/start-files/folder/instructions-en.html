Start the app

  • Mac: double-click Start on Mac.command.
  • Windows: double-click Start on Windows.bat.

A window opens and shows two addresses, and your browser opens the app. Keep the window open while you learn. To stop the app, close the window.

The first time only

  • Mac says the file "cannot be opened" or "Apple could not verify" it: open System Settings, then Privacy & Security. Scroll down and click "Open Anyway" next to the file's name. Double-click the start file again.
  • Mac asks whether to accept incoming network connections: click Allow. Without it, a phone cannot open the app.
  • Windows says "Windows protected your PC": click "More info", then "Run anyway".
  • Windows asks about "Windows PowerShell" and networks: tick private networks and click "Allow access". Without it, a phone cannot open the app.

On a phone or tablet

Connect it to the same Wi-Fi as the computer. In its browser, type the address that the window shows under "On a phone or tablet", for example http://192.168.1.23:8000/. The app also shows it on the page "Your exam books". The computer must keep running the app.

Your progress

Progress stays in the browser of each device, and the phone keeps its own. To move it, use "Back up progress" at the bottom of the app. Start the app the same way each time, so that its address stays the same.

Your exam books

Packs made from a book you own are in the folder app/private. To add one, copy its folder there and start the app again. Only share packs with people in your household.

Give the app to someone else

Copy this whole folder. On a Mac, right-click it and choose "Compress", then pass on the zip file; a Mac then keeps the start file working. On Windows, extract the zip first ("Extract All").

If the app does not start

  • The window says no free port: the app is already running in another window. Use that one, or close it and start again.
  • Mac says you do not have the access privileges to run the file: the folder was copied without its zip. Ask for the zip file again.
  • The phone cannot open the address: check that both are on the same Wi-Fi (not a guest network, not mobile data) and that no VPN is on.
  • Nothing works: the public website has everything except your exam books.
